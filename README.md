# BRB Agency - Diwali Dhamaka Edition 🪔💥

A festive Neo-Brutalist Diwali theme for **BRB Agency**, built strictly with **HTML & CSS** (plus vanilla JS) for zero-dependency GitHub Pages hosting.

---

## 🎨 Aesthetic & Visual Features

- **Neo-Brutalist Diwali Visual Language**:
  - High-voltage palette: Indian Saffron (`#FF6200`), Festive 24K Gold (`#FFD700`), Sindoor Maroon (`#E60039`), Electric Magenta (`#D80082`), and Peacock Teal (`#00F0B5`).
  - Bold, tactile brutalist outlines (`4px solid #111111`) and sharp drop shadows (`5px 5px`, `8px 8px`, `12px 12px`).
  - Typography: `Syne` (display heading weights 700/800/900 italic) + `Space Grotesk` (clean modern sans) + `JetBrains Mono` for code badges.

- **Festive Interactive Elements**:
  1. **Hanging Toran & Fairy Lights Garland**: Dynamic SVG Quadratic Bezier curved rope along the navbar with 32 glowing, pulsing bulbs in festive colors.
  2. **Traditional Hanging Ornaments**: Hand-crafted Neo-Brutalist SVG Akash Kandils (Diwali sky lanterns with fluttering streamers), terracotta clay Diyas with animated flickering flames, and rotating ground Chakris swaying softly on strings.
  3. **Interactive Sparkler & Fireworks Canvas**:
     - Ambient golden sparks rising upward like diya heat and festive night embers.
     - Phooljhadi (sparkler) mouse trail cursor effect.
     - Click anywhere to launch a colorful neo-brutalist cracker burst with Web Audio synthetic sound pops.
  4. **Diwali Deal Badge**: Spinning ground chakri + glowing diya with a 25% OFF offer linking to Google Forms.
  5. **Ambient Sitar / Festive Audio**: Floating music toggle button with safe asynchronous playback control.
  6. **Interactive "Burst Cracker" & "Light a Diya" buttons**: Trigger festive particle celebration bursts across the screen.

## 🚀 Deployment to GitHub Pages

This project is 100% static: pure HTML5, CSS3, and browser-native JavaScript with CDN-powered Tailwind CSS and Lucide Icons.

### Steps:
1. Push the contents of the `diwali` directory to your GitHub repository (e.g. `main` branch).
2. Go to **Settings > Pages** in your GitHub repository.
3. Under **Build and deployment**:
   - Source: **GitHub Actions** (uses the included `.github/workflows/static.yml`) or **Deploy from a branch** (`/root`).
4. Your site will be live instantly!
